# Tranquil — 100 / 100 checklist

Use this list when you want **nothing meaningful left as “known loose ends.”** Check items off as you go; order roughly reflects **unblock heirs/cron first**, then **data discipline**, then **confidence**.

---

## 1. Auth & middleware (blocking heirloom + cron + export)

- [ ] **`auth.config.ts` — `callbacks.authorized`** allows **without session**:
  - [ ] `/heirloom-access` (and any query variants you rely on)
  - [ ] `/api/cron/*` (handlers enforce `Authorization: Bearer CRON_SECRET`)
  - [ ] `/api/export` when `heirloomToken` query param is present
- [ ] Re-read **`src/middleware.ts`** `matcher`: confirm **no accidental skips** of `/api/auth/*` break OAuth routes; confirm cron/export/heirloom paths are **not** redirected to `/signin`.
- [ ] Manual smoke: **logged-out** GET `/api/cron/dormancy` with wrong secret → **401**; correct Bearer → **200** (or expected JSON).
- [ ] Manual smoke: **logged-out** `/api/export?heirloomToken=…` with valid vs revoked/expired token.

## Definition of done

You’re at **100 / 100** when:

1. Middleware allows the documented public/heirloom/cron/export paths **and** you’ve smoke-tested them logged out.  
2. Schema changes are represented by **committed migrations** (or you explicitly chose push-only and documented why).  
3. **`npm run build`** (and lint if enforced) passes from clean checkout.  
4. Seeds + Collections IDs verified; xAI REST assumptions reconciled with live docs or logs.  
5. Core user flow + worker + cron paths exercised in an environment that matches production topology.

When every box above is checked, treat the codebase as **integration-complete** with **verified runtime behavior**, not merely **feature-complete**.
